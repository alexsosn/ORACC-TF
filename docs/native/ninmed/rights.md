The source project's `data/asbp/ninmed/metadata.json` identifies `asbp/ninmed`, source URL `http://oracc.org/asbp/ninmed` and `UTC-timestamp: 2024-07-05T13:32:14`. The original ORACC JSON source metadata declares **CC0** with URL https://creativecommons.org/publicdomain/zero/1.0/; ORACC's separate data-acquisition guidance also describes **JSON** exports as CC0: https://oracc.museum.upenn.edu/compass/downloads/2_3_Data_Acquisition_ORACC.html .

**Website/editorial materials are separate.** The NinMed project's reuse notice (https://oracc.museum.upenn.edu/asbp/ninmed/Aboutthiswebsite/index.html) says its website contents are **CC BY-SA 3.0**, requires the NinMed Project and Wellcome Trust to be acknowledged and identifies third-party rights, especially **British Museum** images under CC BY-NC-SA 4.0. The converted JSON-only Text-Fabric graph does not grant reuse of website prose, images, external editions or translations.
